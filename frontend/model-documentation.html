HTTP POST Request Payload

Endpoint: ${API_URL}/get-prediction

POST /get-prediction HTTP/1.1
Host: localhost:8000
Content-Type: application/json

{
  "ghi": 650.5,
  "humidity": 45.2,
  "temp": 28.7,
  "is_sun": 0,
  "sunlightTime": 10.5,
  "dayLength": 12.8,
  "SunlightTime_daylength": 0.8203
}

HTTP Response Format

Response status: 200 OK

HTTP/1.1 200 OK
Content-Type: application/json

{
  "Energy": -1.5901462189547506
}
Note on Negative Values: If the model outputs negative numbers (e.g. night scenarios with 0 irradiance), the frontend display logic clamps it to 0.00 Wh while logging the exact raw value.

nn.Sequential(

Preprocessing Pipeline

• Energy: log1p
• GHI: log1p
• Humidity: sqrt
• Sunlight: log1p
• Day Length: sqrt
• Scaler: MinMax [0, 1]
