Python Code Step-by-Step Workflow

Step 1

Data Loading & Cleaning

Downloads the Kaggle renewable energy dataset via kagglehub, validates types, and checks for missing values or duplicates.

Step 2

EDA & Feature Selection

Analyzes outliers using IQR, visualizes correlations via heatmaps, and picks 7 key predictive features (GHI, temp, humidity, etc.).

Step 3

Transformation & Scaling

Applies log/square-root transforms to handle skews, splits training/testing sets, and normalizes values using MinMaxScaler.

Step 4

Training & Prediction

Trains a PyTorch sequential network with MSE loss and Adam optimizer, then reverses scaling and log transformation (expm1).

Note on Negative Values: If the model outputs negative numbers (e.g. night scenarios with 0 irradiance), the frontend display logic clamps it to 0.00 Wh while logging the exact raw value.

Preprocessing Pipeline

Energy: log1p
GHI: log1p
Humidity: sqrt
Sunlight: log1p
Day Length: sqrt
Scaler: MinMax [0, 1]
