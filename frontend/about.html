Project Overview & Objectives

01

Dataset & Feature Engineering

The dataset has data from 2017. It has more than 200K real observations from the Fes laboratory.

02

Neural Network Modeling

We use a Multi-Layer Perceptron (MLP) neural network to predict solar energy.

03

Performance Boost

We improved the model performance by 30%. We did this by improving data preprocessing and the model architecture.

04

MLOps & CI/CD Deployment

We use CI/CD to deploy the project to Google Cloud Run. This follows modern MLOps practices.
